# Visual Views

Thư mục này chứa các bản xem trực quan (HTML độc lập) của tài liệu trong `docs/`. Nguồn sự thật luôn là Markdown ở `business/`, `architecture/`, `implementation/`.

- Chỉ tạo file HTML ở đây **khi có yêu cầu rõ ràng**; không sinh tự động.
- Đặt tên `{feature-or-system}-view.html`; tài liệu Markdown tham chiếu qua liên kết tương đối.
- Hiện chưa có view nào.
