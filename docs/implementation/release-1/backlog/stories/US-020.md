# User Story: US-020 - Quản lý Mô hình AI (Model Manager) & Add-on CUDA

**Tầng tài liệu**: Implementation Layer (`docs/implementation/release-1/backlog/stories/US-020.md`)  
**Release**: release-1 (MVP Windows v0.1)  
**Traceability**: Map to `FR-INS-03`, `FR-INS-04`, `FR-INS-05`, `FR-INS-06` trong [prd.md](../prd.md)  
**Priority**: P0 (Must)  

---

## 1. User Story Statement

**As a** Người dùng hoặc kỹ sư muốn kiểm soát các mô hình AI chạy trên máy của mình  
**I want to** Truy cập trình Quản lý Mô hình (Model Manager) để xem dung lượng, tải thêm/xóa bớt các model STT/LLM, tải add-on CUDA nếu có GPU NVIDIA và nhận thông báo cập nhật ứng dụng tự động  
**So that** Tôi tối ưu hóa được dung lượng ổ đĩa, tận dụng tối đa sức mạnh card đồ họa rời và luôn sử dụng phiên bản phần mềm mới nhất  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy path - Quản lý danh sách mô hình trực quan trong Model Manager]
- **Given** Người dùng vào Cài đặt -> mục Model Manager
- **When** Màn hình hiển thị
- **Then** Hệ thống liệt kê toàn bộ các mô hình AI theo nhóm: Mô hình STT Realtime, Mô hình STT Sau họp, Mô hình LLM Tóm tắt, Mô hình Dịch
- **And** Hiển thị rõ trạng thái: `Đã tải (Dung lượng)` hoặc `Chưa tải`, kèm nút "Tải về" hoặc "Xóa"
- **And** Có nút "Kiểm tra bản cập nhật mô hình" để cập nhật trọng số mới nhất từ Hugging Face mirror

### AC2: [Happy path - Phát hiện GPU NVIDIA & Cài đặt gói add-on CUDA]
- **Given** Máy tính của người dùng có card đồ họa rời NVIDIA (ví dụ: RTX 3060, RTX 4060)
- **When** Người dùng mở Model Manager
- **Then** Hệ thống hiển thị huy hiệu xanh: *"Phát hiện GPU NVIDIA. Bạn có thể cài đặt thêm gói tăng tốc CUDA để tăng tốc độ xử lý"*
- **And** Khi người dùng bấm "Cài đặt gói CUDA", hệ thống tải gói runtime CUDA add-on riêng biệt và kích hoạt cờ GPU trong Sidecar

### AC3: [Management & Integrity - Tải tiếp khi rớt mạng (Resume) & Kiểm tra Checksum]
- **Given** Người dùng đang tải một mô hình LLM có dung lượng 2GB
- **When** Quá trình tải bị ngắt quãng do mạng chập chờn
- **Then** Hệ thống hỗ trợ HTTP Range requests để tiếp tục tải từ byte bị đứt
- **And** Khi tải đủ 100%, hệ thống tự động kiểm tra mã băm SHA-256 để đảm bảo tệp mô hình không bị lỗi trước khi đưa vào sử dụng

### AC4: [Update Management - Tự động cập nhật ứng dụng qua Tauri Updater]
- **Given** Dự án phát hành phiên bản mới trên GitHub Releases (ví dụ v0.1.1)
- **When** Ứng dụng HopHo kiểm tra phiên bản mới
- **Then** Hiển thị hộp thoại thông báo cập nhật kèm danh sách các cải tiến (Changelog)
- **And** Bắt buộc người dùng nhấn "Đồng ý cập nhật" mới thực hiện tải và khởi động lại để áp dụng bản cập nhật

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Storage & Model Directory Invariants** (`docs/architecture/04-deployment-architecture.md` & `05-data-architecture.md`):
   - Toàn bộ model phải được lưu trong thư mục `models/` thuộc thư mục data cô lập.
   - Tuyệt đối KHÔNG tải vào cache mặc định của Hugging Face ở ổ `C:\Users\...\.cache`.
2. **License Compliance Guardrails** (`docs/architecture/06-ai-architecture.md`):
   - Mọi model tải về phải được xác minh giấy phép tương thích (Apache 2.0, MIT hoặc Open-Access thương mại).
   - Tuyệt đối cấm tải tự động các model có điều khoản CC-BY-NC (như NLLB).
3. **Design Principles & Repository Layout** (`docs/architecture/09-design-principles.md` & `10-folder-structure.md`):
   - UI Model Manager đặt tại `apps/desktop/src/components/settings/ModelManager.tsx`.
   - Logic tải model có resume nằm trong `apps/desktop/src-tauri/src/system/downloader.rs`.
