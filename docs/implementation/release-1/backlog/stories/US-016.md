# User Story: US-016 - Cung cấp máy chủ hopho-mcp cho Agent ngoài qua Stdio

**Tầng tài liệu**: Implementation Layer (`docs/implementation/release-1/backlog/stories/US-016.md`)  
**Release**: release-1 (MVP Windows v0.1)  
**Traceability**: Map to `FR-MCP-01..04` trong [prd.md](../prd.md)  
**Priority**: P0 (Must)  

---

## 1. User Story Statement

**As a** Kỹ sư phần mềm sử dụng các công cụ AI Agent (như Claude Desktop, Claude Code, Codex, Antigravity)  
**I want to** Kết nối trợ lý AI của tôi với HopHo thông qua máy chủ Model Context Protocol (`hopho-mcp`)  
**So that** Trợ lý AI có thể tự động truy vấn danh sách cuộc họp, đọc transcript, trích xuất action items và tự động đồng bộ sang Notion/Jira/Slack theo yêu cầu của tôi  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy path - Cung cấp máy chủ MCP độc lập qua chuẩn Stdio]
- **Given** Người dùng cấu hình tool MCP trong file config của Claude Desktop hoặc Antigravity trỏ tới executable `hopho-mcp`
- **When** Agent AI khởi chạy máy chủ MCP
- **Then** Tiến trình `hopho-mcp` tự động xác định thư mục dữ liệu qua file config chung của HopHo
- **And** Kết nối trực tiếp vào SQLite ở chế độ đọc an toàn (WAL mode) mà không phụ thuộc vào việc app HopHo giao diện có đang mở hay không

### AC2: [Tool Coverage - Cung cấp đầy đủ 6 Tools tiêu chuẩn]
- **Given** Máy chủ MCP đã khởi động thành công
- **When** AI Agent gọi phương thức liệt kê công cụ (`tools/list`)
- **Then** HopHo MCP trả về đầy đủ 6 tools:
  1. `list_meetings`: Liệt kê các cuộc họp theo thời gian, workspace, tags
  2. `get_meeting`: Lấy thông tin chi tiết và metadata của một cuộc họp
  3. `get_transcript`: Lấy toàn bộ nội dung phiên âm (có mốc thời gian và tên người nói)
  4. `search_meetings`: Tìm kiếm từ khóa trên toàn bộ transcript bằng SQLite FTS5
  5. `get_action_items`: Lấy danh sách việc cần làm đã được sinh ra
  6. `save_summary`: Cho phép Agent ghi kết quả tóm tắt mới vào cuộc họp

### AC3: [Integration Snippets - Cung cấp sẵn mẫu cấu hình 1-Click]
- **Given** Người dùng vào Settings -> Integrations trong HopHo
- **When** Người dùng chọn tab "Claude Desktop", "Claude Code" hoặc "Antigravity"
- **Then** Hệ thống hiển thị đoạn mã JSON cấu hình mẫu tương ứng với đường dẫn file thực tế trên máy
- **And** Cung cấp nút "Sao chép cấu hình" để người dùng dán trực tiếp vào file config của Agent

### AC4: [Security & Concurrency - Xử lý truy cập đồng thời an toàn với SQLite WAL]
- **Given** Ứng dụng HopHo desktop đang ghi dữ liệu cuộc họp mới
- **When** Cùng lúc đó AI Agent bên ngoài gọi tool `get_transcript` hoặc `search_meetings` qua MCP
- **Then** Thao tác đọc của MCP diễn ra ngay lập tức, không bị khóa (database locked) và không làm gián đoạn luồng ghi âm của app desktop

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Architecture Decisions** (`docs/architecture/03-service-architecture.md`, `05-data-architecture.md`, `08-integration-architecture.md` §3 & `ADR-001`):
   - `hopho-mcp` là một tiến trình Python độc lập chạy qua giao thức stdio (MCP Python SDK).
   - Truy cập SQLite thông qua package dùng chung `packages/hopho_store`. CẤM viết truy vấn thô lặp lại.
2. **Security & Concurrency Invariants** (`docs/architecture/07-security-architecture.md`):
   - Cơ sở dữ liệu SQLite bắt buộc bật chế độ `PRAGMA journal_mode = WAL;` và `PRAGMA busy_timeout = 5000;`.
3. **Design Principles & Repository Layout** (`docs/architecture/09-design-principles.md` & `10-folder-structure.md`):
   - Toàn bộ code MCP đặt tại thư mục `mcp/` ở root monorepo.
