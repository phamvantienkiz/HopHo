# User Story: US-008 - Chạy lại STT chuẩn sau họp hỗ trợ Tạm dừng/Chạy tiếp

**Tầng tài liệu**: Implementation Layer (`docs/implementation/release-1/backlog/stories/US-008.md`)  
**Release**: release-1 (MVP Windows v0.1)  
**Traceability**: Map to `FR-STT-01`, `FR-STT-05`, `FR-STT-07`, `NFR-04`, `NFR-04` trong [prd.md](../prd.md)  
**Priority**: P0 (Must)  

---

## 1. User Story Statement

**As a** Thư ký cuộc họp sau khi kết thúc phiên họp kéo dài  
**I want to** Chạy lại mô hình Speech-to-Text chính xác cao ở chế độ nền với tính năng Tạm dừng (Pause) và Chạy tiếp (Resume)  
**So that** Tôi có một bản transcript chuẩn hóa, ít lỗi chính tả nhất mà không làm đơ giật máy tính và có thể tạm ngưng khi cần làm việc khác  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy path - Chạy lại STT bản chuẩn sau họp]
- **Given** Cuộc họp vừa kết thúc và chuyển sang trạng thái `recorded`
- **When** Người dùng xác nhận "Chạy lại bản chuẩn" (hoặc tự động kích hoạt nếu đã cấu hình)
- **Then** Python Sidecar khởi động tiến trình Batch STT chạy ngầm với độ ưu tiên CPU thấp
- **And** Sử dụng mô hình lớn hơn (ví dụ Whisper large-v3-turbo hoặc PhoWhisper chuẩn hóa) để nhận diện lại toàn bộ file âm thanh cuộc họp
- **And** Lưu kết quả chính thức vào bảng `segments` với `kind = 'final'`

### AC2: [Control Feature - Tạm dừng (Pause) và Chạy tiếp (Resume) an toàn]
- **Given** Tiến trình Batch STT đang xử lý ở mức 45% thời lượng cuộc họp
- **When** Người dùng nhấn nút "Tạm dừng" trên giao diện
- **Then** Sidecar hoàn thành segment hiện tại, lưu checkpoint tiến độ vào SQLite và chuyển tiến trình về trạng thái dừng nghỉ
- **And** Khi người dùng nhấn "Chạy tiếp", hệ thống tiếp tục xử lý từ checkpoint đã lưu mà không phải chạy lại từ đầu

### AC3: [Business Rule - Tối ưu hóa nhận diện nói trộn Việt - Anh (Code-switching)]
- **Given** Cuộc họp công nghệ có nhiều câu nói trộn như "Team cần review PR này trước khi deploy lên staging"
- **When** Batch STT chạy lại
- **Then** Mô hình nhận diện chính xác các từ tiếng Anh chuyên ngành kết hợp tiếng Việt, không bị phiên âm sai lệch dạng phiên âm bồi
- **And** Tỷ lệ WER tổng thể trên tập kiểm thử tiếng Việt được ghi nhận làm số liệu tham chiếu (ngưỡng mục tiêu chốt sau M0)

### AC4: [Performance Constraint - Tốc độ xử lý <= 1x thời lượng họp]
- **Given** Tệp âm thanh cuộc họp có thời lượng 60 phút trên máy chuẩn (i5 Gen10/16GB Only CPU)
- **When** Tiến trình Batch STT chạy liên tục
- **Then** Tổng thời gian hoàn thành phải $<= 60$ phút (Real-Time Factor $RTF <= 1.0$)
- **And** Giao diện hiển thị thanh tiến độ %, thời gian còn lại ước tính và số segment đã xử lý

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Data Model Guardrails** (`docs/architecture/05-data-architecture.md`):
   - Bản ghi transcript chính thức được lưu vào `segments` với `kind = 'final'`.
   - Cập nhật trường `status` của `meetings` thành `processing` khi đang chạy và `ready` khi hoàn tất.
2. **Sidecar Process Guardrails** (`docs/architecture/03-service-architecture.md`):
   - Tiến trình batch chạy trong thread/worker nền riêng biệt, set process priority `BELOW_NORMAL_PRIORITY_CLASS` trên Windows.
3. **Design Principles & Repository Layout** (`docs/architecture/09-design-principles.md` & `10-folder-structure.md`):
   - Logic batch STT nằm trong `sidecar/src/hopho_sidecar/stt/batch.py`.
