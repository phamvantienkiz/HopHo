# User Story: US-014 - Tích hợp linh hoạt 3 nhóm Provider LLM (Local, Cloud, Agent)

**Tầng tài liệu**: Implementation Layer (`docs/implementation/release-1/backlog/stories/US-014.md`)  
**Release**: release-1 (MVP Windows v0.1)  
**Traceability**: Map to `FR-LLM-08`, `FR-DATA-06`, `FR-DATA-07` trong [prd.md](../prd.md)  
**Priority**: P0 (Must)  

---

## 1. User Story Statement

**As a** Kỹ sư phần mềm hoặc người dùng có sẵn tài khoản gói trả phí của Claude, OpenAI hoặc công cụ dòng lệnh Agent CLI  
**I want to** Tùy chọn linh hoạt nhà cung cấp mô hình LLM giữa 3 nhóm: llama.cpp nhúng local, Cloud OpenAI-compatible hoặc Agent CLI headless (`claude -p`, `codex exec`, `agy`)  
**So that** Tôi tận dụng được gói tài khoản sẵn có của mình với chất lượng cao nhất mà không bị phụ thuộc vào một nhà cung cấp duy nhất  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy path - Cấu hình và sử dụng Local LLM (llama.cpp)]
- **Given** Người dùng chọn provider là `llama.cpp` trong màn hình Settings -> LLM Providers
- **When** Người dùng yêu cầu sinh tóm tắt hoặc chat với cuộc họp
- **Then** Python Sidecar tự động nạp mô hình GGUF local đã tải (ví dụ Qwen2.5) qua llama.cpp nhúng sẵn
- **And** Thực thi suy luận hoàn toàn ngoại tuyến 100% trên máy tính cá nhân, không phát sinh bất kỳ kết nối mạng nào

### AC2: [Happy path - Cấu hình Cloud OpenAI-compatible & Lưu key an toàn]
- **Given** Người dùng cấu hình Provider là `Cloud OpenAI-compatible`, nhập Base URL (ví dụ: `https://api.openai.com/v1`) và API Key
- **When** Người dùng bấm "Lưu cấu hình"
- **Then** API Key được mã hóa và lưu trữ an toàn trong Windows Credential Manager thông qua OS keychain API
- **And** Trước mỗi lần gửi dữ liệu cuộc họp lên cloud, ứng dụng hiển thị hộp thoại xác nhận minh bạch: *"Dữ liệu cuộc họp sẽ được gửi tới {Base URL}. Bạn có đồng ý tiếp tục?"*

### AC3: [Happy path - Tích hợp Agent CLI headless]
- **Given** Người dùng đã cài đặt sẵn công cụ CLI như `claude`, `codex` hoặc `agy` trên máy tính
- **When** Người dùng chọn provider là `Agent CLI` và chọn công cụ tương ứng
- **Then** Hệ thống thực thi lệnh version probe để kiểm tra phiên bản CLI tương thích
- **And** Gọi lệnh ở chế độ headless (ví dụ: `claude -p "..."`) để sinh tóm tắt mà không cần người dùng nhập lại API Key

### AC4: [Negative path - Xử lý lỗi API Key không hợp lệ hoặc CLI bị thay đổi cú pháp]
- **Given** API Key Cloud bị hết hạn hoặc lệnh CLI trả về mã lỗi do cú pháp thay đổi
- **When** Yêu cầu xử lý LLM thất bại
- **Then** Hệ thống hiển thị thông báo lỗi chi tiết, không làm ứng dụng bị crash im lặng
- **And** Gợi ý người dùng kiểm tra lại API Key trong Settings hoặc chuyển sang dùng Local LLM

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Security & Key Management Guardrails** (`docs/architecture/07-security-architecture.md`):
   - CẤM lưu API Key dạng văn bản rõ (plaintext) trong database SQLite hoặc file config JSON.
   - Bắt buộc sử dụng crate `keyring` (Rust) để lưu vào Windows Credential Manager.
   - Bắt buộc kích hoạt hộp thoại xác nhận đồng ý gửi dữ liệu ra ngoài (Outbound Consent Gate).
2. **Design Principles & Repository Layout** (`docs/architecture/09-design-principles.md` & `10-folder-structure.md`):
   - Định nghĩa abstract interface `LlmProvider` tại `sidecar/src/hopho_sidecar/llm/base.py` với 3 class triển khai: `LlamaCppProvider`, `OpenAiProvider`, `AgentCliProvider`.
