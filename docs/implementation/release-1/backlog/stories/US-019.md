# User Story: US-019 - Cài đặt ứng dụng .msi & Trình hướng dẫn Onboarding Wizard

**Tầng tài liệu**: Implementation Layer (`docs/implementation/release-1/backlog/stories/US-019.md`)  
**Release**: release-1 (MVP Windows v0.1)  
**Traceability**: Map to `FR-INS-01`, `FR-INS-02`, `FR-STT-03` trong [prd.md](../prd.md)  
**Priority**: P0 (Must)  

---

## 1. User Story Statement

**As a** Người dùng phổ thông không rành về kỹ thuật lập trình (Non-technical / Low-code)  
**I want to** Tải một file cài đặt `.msi` duy nhất, cài đặt ứng dụng chỉ bằng vài cú nhấp chuột và được một trình hướng dẫn (Onboarding Wizard) tự động khảo sát máy tính rồi chuẩn bị sẵn sàng môi trường  
**So that** Tôi có thể sử dụng ngay trợ lý cuộc họp AI mà không cần biết Python, CUDA hay terminal là gì  

---

## 2. Acceptance Criteria (Given-When-Then)

### AC1: [Happy path - Cài đặt trọn gói qua file .msi trên Windows sạch]
- **Given** Một máy tính Windows 10/11 x64 sạch (hoàn toàn chưa từng cài Python, git hay bất kỳ công cụ phát triển nào)
- **When** Người dùng tải và chạy file cài đặt `HopHo-Setup-v0.1.msi`
- **Then** Trình cài đặt hoàn tất việc giải nén app Tauri và nhúng sẵn Python sidecar đã đóng gói độc lập vào máy
- **And** Tạo biểu tượng HopHo trên Desktop và Start Menu
- **And** Người dùng nhấp đúp là ứng dụng mở lên ngay lập tức mà không báo lỗi thiếu thư viện runtime

### AC2: [Happy path - Luồng Onboarding Wizard 5 bước trực quan]
- **Given** Người dùng khởi chạy ứng dụng lần đầu tiên
- **When** Ứng dụng phát hiện chưa có cấu hình khởi tạo
- **Then** Trình hướng dẫn Onboarding Wizard tự động hiển thị với 5 bước rõ ràng:
  1. *Bước 1 - Chọn thư mục lưu trữ dữ liệu*: Gợi ý ổ đĩa trống nhất
  2. *Bước 2 - Khảo sát phần cứng nhanh*: Đo CPU, RAM và card đồ họa
  3. *Bước 3 - Đề xuất gói mô hình*: Gợi ý gói Lite, Standard hoặc Pro phù hợp
  4. *Bước 4 - Tải mô hình ban đầu*: Tải model STT nhẹ kèm thanh tiến độ
  5. *Bước 5 - Kiểm tra âm thanh*: Cho người dùng thử mic và loopback qua VU meter
- **And** Khi hoàn tất, chuyển thẳng người dùng vào màn hình chính sẵn sàng sử dụng

### AC3: [Edge Case - Khảo sát phần cứng và phân loại gói chính xác]
- **Given** Máy tính của người dùng có cấu hình Intel Core i5 Gen10 / 16GB RAM (chỉ có đồ họa tích hợp)
- **When** Wizard thực hiện khảo sát phần cứng
- **Then** Hệ thống phân loại chính xác vào gói **Standard** và đưa ra khuyến nghị: *"Cấu hình máy của bạn đáp ứng hoàn hảo chế độ Realtime STT và xử lý sau cuộc họp"*
- **And** Tự động chọn sẵn gói model Standard để tải về

### AC4: [Negative path - Rớt mạng khi đang chạy Wizard tải model ban đầu]
- **Given** Ở Bước 4 của Wizard, người dùng đang tải model thì mạng Internet bị ngắt
- **When** Mất kết nối
- **Then** Wizard hiển thị trạng thái "Mất kết nối mạng. Đang chờ kết nối lại...", lưu lại phần trăm byte đã tải
- **And** Khi mạng có lại, quá trình tải tự động tiếp tục (resume) mà không bắt người dùng tải lại từ 0%

## 3. Architecture Guardrails for Coding Agents (BẮT BUỘC ĐỌC TRƯỚC KHI CODE)

> ⛔ **Cảnh báo cho AI Coding Agent**: Trước khi sinh hoặc sửa code cho User Story này, Agent BẮT BUỘC phải đọc và tuân thủ các tài liệu kiến trúc bất biến sau:

1. **Packaging & Deployment Guardrails** (`docs/architecture/04-deployment-architecture.md`):
   - Sử dụng WiX Toolset tích hợp qua Tauri Bundler để sinh file `.msi`.
   - Sidecar Python được biên dịch thành file thực thi duy nhất (PyInstaller/Nuitka) đặt trong `src-tauri/binaries/`.
2. **Design Principles & Repository Layout** (`docs/architecture/09-design-principles.md` & `10-folder-structure.md`):
   - Màn hình Onboarding Wizard đặt tại `apps/desktop/src/components/onboarding/OnboardingWizard.tsx`.
   - Lưu trạng thái hoàn tất onboarding vào config local `app_initialized = true`.
