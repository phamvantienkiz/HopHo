# API Surface — Release 1 (v1)

**Tầng tài liệu**: Implementation Layer (`docs/implementation/release-1/api/v1.md`)

**Ngày cập nhật**: 2026-10-15

HopHo không có API công khai qua Internet. Release 1 có 3 bề mặt giao tiếp; đặc tả chi tiết là nguồn duy nhất ở các tài liệu dưới đây để tránh trùng lặp.

| Bề mặt | Đặc tả |
|---|---|
| Rust Core ↔ Python Sidecar (WebSocket `/ws/session`, REST `/api/batch/*`, `/health`) | [08-integration-architecture.md](../../../architecture/08-integration-architecture.md) §2 |
| UI ↔ Rust Core (Tauri commands/events) | [technical-design.md](../technical-design.md) §3.1 |
| Agent ngoài ↔ `hopho-mcp` (stdio, 6 tools) | [08-integration-architecture.md](../../../architecture/08-integration-architecture.md) §3 |

Mọi thay đổi hợp đồng giao tiếp phải cập nhật tài liệu 08 trước, sau đó mới sửa code.
